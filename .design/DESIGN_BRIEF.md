# DESIGN BRIEF · 摇滚朋克个人展示站

## 项目目标
为龙猫先生构建一个摇滚朋克风格的个人展示页，打破常规简历的平庸感，强调反叛、能量、粗粝质感与高端视觉控制力。

## 内容来源
基于 `projects/resume/copywriting.md` 中的高端版文案。

## 核心页面
1. Hero：视觉冲击，大字报式姓名 + 身份标签
2. About：反差感文案 + 粗粝排版
3. Experience：时间线/朋克海报式经历卡片
4. Projects：项目展示，撕裂边缘/胶带/印章元素
5. Skills：技能标签云/仪表盘
6. Contact：CTA，邮箱直接展示

## 视觉方向
- **色彩**：黑底 + 血红/锈橙/做旧白，少量霓虹粉或毒绿点缀
- **字体**：无衬线粗体 + 等宽字体 + 哥特/手写破坏感装饰字体
- **质感**：噪点、划痕、胶带、撕纸边缘、印章、喷涂
- **动效**：抖动、故障(glitch)、打字机、闪烁、滚动视差
- **布局**：非对称、出血、大留白、打破网格
- **反 AI-slop 禁令**：
  - 禁止圆润大圆角卡片
  - 禁止柔和渐变背景
  - 禁止 emoji 装饰
  - 禁止居中对称的"作品集三段式"
  - 禁止 Tailwind 默认阴影

## 技术栈
React + Vite + Tailwind CSS + GSAP
