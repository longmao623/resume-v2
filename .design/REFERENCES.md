# References · 摇滚朋克个人站参考

## 搜索结果结论
GitHub 上直接匹配 "punk portfolio" / "rock personal website" 的开源完整项目较少。开源社区更多偏向：
- neobrutalism（新粗野主义）
- clean minimal portfolio
- 3D / macOS / Google Search themed portfolio

这些风格要么太卡通，要么太 corporate。摇滚朋克方向更适合从视觉原则出发原创，而非 fork 现成模板。

## 参考方向

### 1. 新粗野主义 Neo-Brutalism
- 来源：`github.com/topics/neobrutalism`
- 可取之处：粗黑边框、硬阴影、高对比色、非对称布局
- 问题：通常用亮色块，偏卡通，需要往暗黑、肮脏、破坏感方向调整

### 2. Brutalist Portfolio 视觉案例
- 来源：Dribbble 搜索 "brutalist-portfolio"
- 可取之处：大字报式排版、黑白为主、强字体层级、杂志感

### 3. 朋克设计原则（原创参考）
- **DIY 美学**：看起来像 zine / 传单 / 海报，不是精致企业站
- **破坏感**：撕裂边缘、划痕、胶带、污渍、印章
- **高对比**：黑底 + 血红/锈橙/毒绿，偶尔全白反转
- **字体冲突**：粗体无衬线 + 等宽 + 哥特装饰字体混排
- **非对称**：元素故意偏移、出血、打破网格
- **动态粗暴**：glitch、抖动、闪烁、打字机、快速切换

## 设计决策
不 fork 任何开源模板，直接原创一个单文件 HTML/React 摇滚朋克个人站。原因：
1. 现有开源案例没有直接匹配的风格
2. 原创更能体现 anti-AI-slop 的差异化
3. 单文件更可控，便于快速迭代
